# Papilio 1.2.0

Python 3.13+ is required. This additive release introduces an optional MCP
server integrated with Papilio's module discovery and existing Dishka providers.

## MCP tools using existing services

Install the MCP extra, generate a module, and enable MCP in your application:

```bash
pip install 'papilio[mcp] @ https://github.com/stupidprogrammer4/papilio/releases/download/v1.2.0/papilio-1.2.0-py3-none-any.whl'
papilio module assistant --plain --mcp
```

```python
app = create_app(mcp=True)
```

The Streamable HTTP endpoint is `/mcp/`. `Bootstrapper.boot_mcp_tools()` discovers
explicit `MCPRouter` registrations in each selected module's `tools/` package.
Tool parameters annotated with `FromDishka` receive dependencies from the same
application container used by HTTP handlers; injected parameters are absent from
the client input schema. Each invocation has its own request scope and closes
its resources after completion, failure or cancellation.

`--mcp` works with CRUD, CQRS, context and plain module generation. Generated
tools call the existing service, with no duplicate business logic or HTTP
response envelope. Services retain their own transaction boundaries.

The SDK owns protocol handling and typed input/output conversion. Papilio
composes its lifespan with the host application's resources. Duplicate tool
names fail at startup. Without explicit activation, MCP tool modules and the
optional SDK are not imported. Existing HTTP applications need no migration.

See the [MCP guide](../guide/mcp.md) for explicit registration, alternate paths,
host/origin configuration and access boundaries. Authentication policy remains
application-owned; FastAPI route dependencies do not automatically protect tools.
This release exposes tools, not a resources/prompts API or background task API.

## Other additions since 1.1.0 preparation

- `TimeField` maps `datetime.time` to a SQL time-of-day column without timezone.
- `EnumField` accepts `native_enum`, `values_callable` and `length` for explicit
  text-backed enum mappings while retaining its existing defaults.
- `BaseTable.table_name` supports an explicit application table name.
- Binary file helpers support bounded asynchronous reading and streaming writes.
- `RedisClient.count_keys()` counts matching keys incrementally using SCAN,
  with an optional filter; results remain weakly consistent during concurrent
  changes to Redis.

## Verification boundaries

MCP checks cover SDK clients over ASGI HTTP, modern discovery and the legacy
handshake, provider isolation, cancellation cleanup, error handling, generated
modules and transaction behavior. The database matrix exercises PostgreSQL,
MySQL, MariaDB and SQLite. Live Oracle/SQL Server servers and external assistant
applications are outside this release's validation matrix. No production
throughput or universal compatibility claim is made.
