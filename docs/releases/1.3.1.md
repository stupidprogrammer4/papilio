# Papilio 1.3.1

The optional Pydantic AI adapter validates native Function Tool argument
contracts before execution or deferred write approval. Invalid inputs become
failed SDK tool results, allowing the model to provide a corrected call without
ending the conversation with an internal validation exception.

Injected arguments remain protected. Error feedback does not expose input
values or caller-controlled field names. Validated models do not replace wire
arguments, preserving application decoding and validation contracts.

Application authorization, approval, transaction ownership and retry settings
remain unchanged. No database migration is required. See the
[Function Tools guide](../guide/function-tools.md) for integration details.
