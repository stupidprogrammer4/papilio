# Papilio 1.3.2

The optional Pydantic AI adapter gives actionable validation feedback using
declared field names and standard Pydantic error codes. Models can identify
which inputs need correction while application guards remain authoritative.

Feedback is bounded and excludes input values, arbitrary dictionary keys,
custom error messages and context. Unknown error codes become a fixed
validation error. Injected arguments remain protected before deferred approval.

Validation, independent request scopes, approval and zero automatic retries
are unchanged. No database migration is required. See the
[Function Tools guide](../guide/function-tools.md) for integration details.
